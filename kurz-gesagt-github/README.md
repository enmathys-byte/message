# Kurz gesagt.

Ein offenes Nachrichtenfenster für Fragen, Ideen und kurze Nachrichten an Nicola.

**Webseite:** https://enmathys-byte.github.io/kurz-gesagt/

Alle Besucher können schreiben und den gemeinsamen Verlauf lesen. Nachrichten erscheinen in hellen Chatblasen mit Zeitstempel. Nicola kann sich über **Admin** mit einem Passwort anmelden und in grünen Chatblasen antworten – mit Text oder Links zu Dateien.

Die Webseite wird von GitHub Pages bereitgestellt. Der Nachrichtenspeicher und die Passwortprüfung laufen separat über einen Sites-Dienst. `config.js` enthält dessen öffentliche Adresse; Zugangsdaten sind nicht in diesem Repository gespeichert.

## Veröffentlichung

In den Repository-Einstellungen unter **Pages** die Quelle **Deploy from a branch**, Branch **main**, Verzeichnis **/ (root)** wählen.

## Dateilinks

Dateien zuerst bei einem geeigneten Anbieter hochladen und anschliessend deren HTTP- oder HTTPS-Link als Admin-Antwort einfügen. Die Webseite selbst bietet keinen Datei-Upload.
